# SIH26044 — Skill Intelligence Platform

> AI-powered platform connecting academia, students and industry through skill mapping, readiness analysis and competency-based opportunity matching.

## 🎯 Problem

Students often struggle to understand which skills are required for their target careers and how ready they are for real industry opportunities.

Institutes and academicians need better visibility into student readiness, while industry needs a more competency-focused way to discover suitable candidates.

## 💡 Solution

Our platform creates a continuous skill-intelligence loop:

**Profile → Assess → Identify Gap → Upskill → Verify → Match**

## 🚀 Core Features

- AI-assisted skill extraction
- Skill normalization
- AI Skill Graph
- Skill-gap analysis
- Personalized learning roadmap
- Skill verification
- Dynamic readiness score
- Competency-based internship matching
- Institute skill-readiness analytics
- Academia–industry collaboration

## 🛠️ Technology

**Frontend:** React.js + Tailwind CSS

**Backend:** Python + FastAPI

**Database:** PostgreSQL

**AI/ML:** Python + NLP + scikit-learn

**API:** REST + JSON

**Authentication:** JWT
